# L'ENCRE — Студия тонкой татуировки и авторской графики

Официальный веб-сайт и интерактивный каталог эскизов студии авторской татуировки **«L'ENCRE»**. 

Проект разработан как высокоскоростное прогрессивное веб-приложение (PWA) с акцентом на академическую эстетику, безупречную мобильную эргономику и полную автономность без необходимости постоянного подключения к сети.

---

## Концепция и направления студии

Студия **L'ENCRE** специализируется на деликатной графике тонкой иглой (диаметр спайки 0.18–0.25 мм), ботанических иллюстрациях и античной микро-гравюре. Все работы выполняются сертифицированными веганскими пигментами премиум-класса с соблюдением европейских стандартов асептики и одноразовых стерильных картриджей.

### Основные стилистические направления каталога:
* **Ботаническая микро-иллюстрация**: точные флористические мотивы (дикий папоротник, пионы, реликтовое гинкго билоба, средиземноморская олива и лаванда).
* **Fine Line & Контурная пластика**: анатомическая посадка вдоль естественных линий тела (ключицы, рёбра, предплечья).
* **Академическая гравюра и античность**: римская архитектура, небесные астролябии, зодиакальные созвездия.
* **Фауна и анималистика**: изящные ласточки, лунные мотыльки, японские журавли и спящие лисы в микро-детализации.

## Ключевой функционал веб-приложения

* **Интерактивный скетчбук (12 авторских эскизов)**: каждый эскиз содержит фиксированную стоимость, анатомические зоны посадки, габариты в сантиметрах и расчётное время сеанса.
* **Живая фильтрация и поиск**: мгновенный отбор работ по тегам (*Ботаника*, *Fine Line*, *Геометрия*, *Миниатюра*) и контекстный поиск по анатомическим зонам (*ключица*, *предплечье*, *рёбра*).
* **Полноэкранный Lightbox-просмотрщик**: детальное изучение микро-штриховки каждого эскиза с возможностью мгновенного перехода к бронированию.
* **Форма онлайн-записи на примерку**: выбор удобного города, резидента, даты сеанса и фиксация эскиза без предоплаты.
* **Интерактивная памятка по заживлению и FAQ**: правила ухода за профессиональной плёнкой Suprasorb F, график восстановления кожи и рекомендации по гигиене.
* **Автономный PWA-режим (Service Worker `lencre-cache-v8`)**: все эскизы, шрифты и логика кэшируются локально при первом посещении. Сайт полноценно открывается и работает даже при полном отсутствии интернета или нестабильной связи.
* **Адаптивная эргономика**: оптимизация под экраны 360–390 px, зоны кликабельности 40–44 px, отсутствие горизонтальных сдвигов и защита от нежелательного зума на iOS.
* **Social Preview & Open Graph**: корректные мета-данные (`og:image`, `og:title`, `og:description`) для привлекательного отображения ссылок в мессенджерах (Telegram, WhatsApp).

## Локальный запуск

Сайт представляет собой статический веб-проект и не требует сборки бэкенда:

```bash
# С использованием Python 3
python -m http.server 8000

# С использованием Node.js (npx serve)
npx serve .
```

После запуска перейдите в браузере по адресу: `http://localhost:8000/`.
